# Material 3 Expressive Shapes (Lite)

Лёгкая версия живых обоев с парящими фигурами в стиле Material 3 Expressive. Два слоя — крупные фигуры на фоне и чёткие фигуры с морфингом на переднем плане, плюс мелкие акцентные фигуры. Палитра берётся из Material You автоматически либо задаётся вручную.

## Что происходит на экране

Фигуры дрейфуют, сталкиваются и меняют форму при столкновении (переход между лепестковыми фигурами, кругом и квадратом). Размер и количество углов у каждой фигуры случайны в заданном диапазоне. При касании фигуры рядом с пальцем отталкиваются и подсвечиваются. На заблокированном экране у фигур появляется обводка.

## Настройки

- **AMOLED-тема** — чистый чёрный фон вместо цвета Material You
- **Отключение движения** — фигуры остаются на месте
- **Акцентные цвета** — свои primary/secondary/tertiary вместо системных
- **Количество фигур** — отдельно для заднего, переднего плана и акцентов (включая 0)
- **Размер и углы фигур** — диапазон случайных значений для каждого слоя
- **Затемнение заднего плана** и **скорость движения**

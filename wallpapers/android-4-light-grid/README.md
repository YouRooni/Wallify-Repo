# Android 4 Light Grid

Автор: **nector**

Неофициальная реконструкция характерных живых обоев Android 4: ровная квадратная мозаика с треугольными гранями внутри каждой плитки. По самой сетке движутся светящиеся плитки: одна самая яркая, остальные постепенно затухают.

Настройки оформлены в стиле Material Design 3 / Monet: плотность сетки, количество полос, свечение, яркость, скорость, параллакс, палитра, затемнение и зерно рисунка.

# 🌊 Fluids Wallpaper

> Порт динамических обоев Fluids с Lively Wallpaper на Wallify.

---

##  Описание

Интерактивные обои с симуляцией жидкости на WebGL. Реагируют на касания и акселерометр.

---

## Возможности

- Реалистичная симуляция жидкости
- Взаимодействие через касания
- Поддержка акселерометра
- Разноцветный режим
- Эффекты свечения и лучей
- Фоновое изображение
- Гибкие настройки

---

## Настройки

**Симуляция:**
- Качество отрисовки
- Разрешение симуляции
- Радиус всплеска
- Завихренность
- Давление

**Акселерометр:**
- Всплеск при рывке телефона
- Чувствительность

**Визуал:**
- Разноцветный режим
- Тени (Shading)
- Визуализатор звука
- Случайные всплески

**Свечение:**
- Bloom (свечение)
- Солнечные лучи

**Фон:**
- Цвет фона
- Фоновое изображение

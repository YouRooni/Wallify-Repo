# 80s Retro Room

Обои в пиксельном ретро стиле

Телевизор с возможностью взаимодействия с ним (переключение каналов, дергания антенн), спящий кот на телевизоре, кассеты, окно и прочие элементы комнаты

**Большая часть компонентов обоев - GLSL шейдеры**

**Поэтому для нормальной работы обоев рекомендуется отключить "Программную отрисовку"**

Все цвета обоев адаптируются под вашу Monet палитру

---

## Энергосбережение

Комплект обоев не помечен как энергоэффективный (`isLite = false`)
